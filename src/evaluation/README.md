# src/evaluation/

Các module liên quan đến đánh giá kết quả mô hình.

## Nội dung

- **`metrics.py`** — Tính toán các chỉ số đánh giá mô hình (accuracy, precision, recall...).
- **`visualization.py`** — Vẽ biểu đồ trực quan hóa kết quả (confusion matrix, so sánh mô hình...).
- **`__init__.py`** — Đánh dấu `evaluation` là một Python package con.
