# src/data/

Các module liên quan đến việc đọc và xử lý dữ liệu.

## Nội dung

- **`loader.py`** — Đọc dữ liệu từ file (csv...) vào chương trình.
- **`preprocessing.py`** — Tiền xử lý dữ liệu: làm sạch, biến đổi, tách tập.
- **`feature_engineer.py`** — Xây dựng/biến đổi các đặc trưng (feature) dùng cho mô hình.
- **`__init__.py`** — Đánh dấu `data` là một Python package con.
