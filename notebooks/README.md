# notebooks/

Các notebook dùng để thử nghiệm và chạy từng bước của dự án.

## Nội dung

- **`preprocessing.ipynb`** — Xử lý dữ liệu thô: làm sạch, biến đổi, tách tập train/val/test.
- **`main.ipynb`** — Notebook chính: huấn luyện và đánh giá các mô hình.
- **`hyperparameter_tuning.ipynb`** — Tinh chỉnh tham số cho các mô hình.
